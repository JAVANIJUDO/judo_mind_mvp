# Official Rule and Safety Review Readiness / آمادگی بازبینی قانون و ایمنی رسمی

Stage: `JM-S0.4-B`

Status: `BLANK FUTURE-REVIEW TEMPLATE / NO ASSIGNMENT / NO DECISION`

وضعیت: `قالب خالی برای بازبینی آینده / بدون انتساب / بدون تصمیم`

This package prepares a future qualified human review of one exact acquired
official document. It does not assign a reviewer, record a completed review,
approve a rule, approve safety or science, create eligibility, or enable
production.

این بسته فقط بازبینی انسانی واجدصلاحیتِ یک سند رسمی دقیق و دریافت‌شده در آینده
را آماده می‌کند. این سند هیچ بازبینی را به شخصی واگذار نمی‌کند، بازبینی انجام‌شده
ثبت نمی‌کند و تأیید قانون، ایمنی، علم، eligibility یا فعال‌سازی تولیدی ایجاد
نمی‌کند.

## Entry prerequisites / پیش‌نیاز ورود

- The file must have been acquired in a separately authorized stage.
- Provenance and SHA-256 must be recorded after acquisition.
- Exact identity, issuing body, version, effective date and supersession state
  must be available or explicitly unresolved.
- The applicable reviewer roles must be selected from
  `JM_RULE_SAFETY_REVIEW_ROLE_MATRIX.csv` without inventing a person.
- A candidate ID (`JM-ODC-*`) is not a canonical source ID (`JM-SRC-*`).

- فایل باید در مرحله‌ای جداگانه و مجاز دریافت شده باشد.
- provenance و SHA-256 باید پس از دریافت ثبت شوند.
- هویت دقیق، نهاد صادرکننده، نسخه، تاریخ اجرا و وضعیت جایگزینی باید موجود یا
  صریحاً unresolved باشند.
- نقش‌های لازم باید از ماتریس نقش بازبین انتخاب شوند؛ نام شخص نباید ساخته شود.
- شناسه نامزد `JM-ODC-*` شناسه منبع رسمی `JM-SRC-*` نیست.
